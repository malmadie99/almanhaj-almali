# المنهج المالي

قالب مجاني لتنظيم راتبك ومصروفاتك وديونك واستثمارك، في صفحة وحدة تشتغل على الجوال والكمبيوتر.

**افتح المنهج:** https://malmadie99.github.io/almanhaj-almali/

## وش يسوي
- معالج إعداد لأول مرة: الراتب ويوم نزوله، أرصدة الحسابات، وميزانية كل بند.
- تسجيل الدخل والمصروفات والتحويلات بين الحسابات.
- «هذا الشهر لحظيًا»: كم معك، كم يوم باقي على الراتب، وكم تقدر تصرف باليوم.
- ميزانية لكل بند مع تنبيه لما تقرب أو تتجاوز.
- تصنيفات تقدر تضيفها وتعدلها وتحذفها.
- متابعة الاستثمار، وخطة سداد الدائنين (الأصغر أولًا)، وميزانية مشروع.
- أرشيف شهري ومقارنة بين الأشهر.

## خصوصيتك
بياناتك تنحفظ في متصفحك على جهازك بس، وما توصل لأي سيرفر ولا لأي أحد. لو مسحت بيانات المتصفح أو غيّرت الجهاز تضيع، فصدّر نسخة احتياطية من آخر الصفحة بين فترة وفترة.
